# Novel 产物

这里只放打好的包。源码在 [novel](https://github.com/15697405218/novel)。

目前两份，都从 [Releases](https://github.com/15697405218/novel-releases/releases) 下载：

- **Windows**：`Novel-Setup.exe`。安装到 `%LOCALAPPDATA%\Novel`，不需要管理员权限。
- **Android**：`Novel-android-debug.apk`。调试签名，可以直接装。正式签名包需要 Chaquopy 许可证。

安装包不进 Git。单个文件接近 GitHub 的 100 MB 限制，放在 Release 里即可替换，不用把历史越积越大。
