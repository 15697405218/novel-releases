# Novel

桌面写作程序，手机上也能接着写。正文、设定、对话和模型密钥都留在这台设备上，请求直接发到模型供应商。

下载在 [Releases](https://github.com/15697405218/novel-releases/releases/latest)。只保留当前这一版。

- **Windows**：`Novel-Setup.exe`。安装到 `%LOCALAPPDATA%\Novel`，不需要管理员权限。
- **Android**：`Novel-android.apk`。可以直接安装。

## 能做什么

一本书里可以有分卷、章节、大纲、文风和故事地图。设定集分开记角色、地点、世界观、情节线和笔记。每一章可以写摘要、节拍和绑定。电脑上的正文按富文本编辑，全书字数只统计正文。章节改过会留下版本。

书架上可以新建作品，也可以导入本地的 `.txt` 或 `.md`。写完能导出成 Markdown，或导出成网文用的纯文本。

AI 助手先接到你的话。问事情由它直接答。要起草、续写、改稿、删改章节、大纲、文风或设定时，它把活交给写作模型。写入书里之前，对话里会出一张卡片，接受之后才保存。审核和朱雀 AI 检测另用各自的模型，只有你开口要求时才跑。检测结论会留下来，改正文不会自动重测，也不会按结论自动改稿。

模型在「AI 服务」里连接。可以接 OpenAI、Anthropic、Gemini、OpenRouter、Groq、Cohere、Ollama、New API，以及任何兼容 OpenAI 的接口。每个连接可以标成主调度、写作或审核，同一个角色只挂在一个连接上。一本书可以改用别的模型，也可以关掉审核。朱雀密钥写在这本书的设置里。

语音只用已经保存的豆包密钥。说完再点一次麦克风。DeepSeek 和 Kimi 不能听写。

模型连接和每本书的模型选择可以导出成一份配置，再导入到另一台设备。文件里有密钥，只留给自己。

安卓和桌面用同一套书的结构。手机上的章节按纯文本编辑，保存后是简单段落，电脑上的加粗和对齐不会原样留住。两边的书库不是同一份文件。

## 怎么用

1. 安装 Windows 包，或把安卓包装到手机上。
2. 打开后注册或登录。密码只在这台设备上，这里不能重置。没有配置云端地址时，电脑版会自己把本机账号服务带起来。若 `%APPDATA%\Novel\auth_url.txt` 里有一行云函数地址，登录就发到那台云函数。
3. 打开「AI 服务」，填上接口地址、模型名和密钥，再勾选它担任主调度、写作或审核。本地模型的密钥可以留空。
4. 在书架新建一本书，或导入一本 `.txt` / `.md`。
5. 在正文里直接写。要接着写当前章，用「续写」。要让助手改书，在对话里说清楚改哪一章、大纲还是设定，然后接受卡片。
6. 需要审稿或看 AI 占比时，在对话里直接说。朱雀先在「本书设置」里打开并填上密钥。
7. 换电脑时，用「导出配置」把模型连接带走。书稿仍在原来的书库里。

Windows 的书库在 `%APPDATA%\Novel\users\<用户 id>\library.sqlite`。安卓的书在应用私有目录的 `library.sqlite`，模型密钥只留在这台手机上。
